# Crochet Companion

A small Android app (Java, English UI) for crocheters:

- **Stitch Guide** – common stitches with abbreviations, difficulty and step-by-step instructions (tap a stitch).
- **Row Counter** – count rows and stitches; values are saved automatically (SharedPreferences).
- **Hook Size Chart** – metric / US hook sizes with the yarn weights they suit.

## Run
Open the `CrochetApp` folder in Android Studio and press Run (min SDK 21).
